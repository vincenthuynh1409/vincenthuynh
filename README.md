# Vincent Huynh — Personal Portfolio Website

A personal portfolio website for showcasing my bio, experience, achievements, projects/notes, and contact information.

**Live Website Link:** https://vincenthuynh-azure.vercel.app/

## Portfolio

The website is organized into several sections documenting my academic and technical journey:

- **Education** = My academic background and cybersecurity-focused coursework.

- **Experience** = Programs, competitions, volunteering, and hands-on experiences that have helped me develop practical technical and problem-solving skills.

- **Achievements** = A collection of awards, certifications, competition results, and other milestones from my academic and cybersecurity journey.

- **Projects** = A collection of cybersecurity projects, research, tools, notes, labs, and CTF write-ups.

- **Contact** = Ways to connect with me, including GitHub, Devpost, TryHackMe, and email.

## Website Tech Stack
* HTML5
* CSS3
* JavaScript
* Git
* GitHub Pages
* Vercel

## Features

- Modern responsive portfolio design
- Dark, minimal cybersecurity-themed UI
- Mobile-friendly responsive layout
- Social and professional profile integration
- Contact and networking section
- Custom images, profile picture, and achievement graphics
- Lightweight static website
- GitHub Pages & Vercel ready deployment
- Simple, easily customizable HTML/CSS/JavaScript structure
